# Voxmate voxlets

Voxmate-provided public voxlets — audio-first apps for blind users, running on the [Voxmate](https://voxmate.com) platform. Each folder is one voxlet, buildable by the Voxmate platform via its github ident: `github.com/voxmate/voxlets/<name>`.

Voxlets are written against the published SDK packages [`@voxmate/voxmate`](https://www.npmjs.com/package/@voxmate/voxmate) (engine typings, intrinsics, utilities) and [`@voxmate/orc`](https://www.npmjs.com/package/@voxmate/orc) (Orchestrator and Activity bases), installed from this repo's `package.json` at build time.

| Voxlet | What it is |
|---|---|
| audiobooks | audiobook player (LibriVox) |
| battleship | classic battleship, by voice |
| blackjack | blackjack against the house |
| clips | short-audio clips player |
| fileplayer | play your own audio files |
| knowville | trivia town |
| mathdoku | KenKen-style number puzzles |
| news | news reader |
| play | media playback hub |
| podcasts | podcast player |
| quiz | quiz game |
| radio | internet radio |
| sudoku | sudoku, by voice |
| voxville | word town |
| youtube | YouTube audio player |
